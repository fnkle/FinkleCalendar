# **Finkle Calendar**

<img width="1161" height="808" alt="image" src="https://github.com/user-attachments/assets/d09bc579-a58c-4c02-8197-95d55123e6f7" />

A simple calendar app to implement a MVVM application using C# and WPF following my placement year of uni. In order to have a greater understanding of the MVVM architecture from the ground up.
Currently it allows the user to create and edit events on any day. With the events being persisted between sessions.

## **Possible improvements for the future:**
 - General UI improvements to the calendar
 - Recurring events
 - Reminders of upcoming events
